# factorial.py
Factorial Calculator
Project Description

This is a simple Python project that calculates the factorial of a given number.

The program accepts a number as input and calculates its factorial. The factorial of a non-negative integer n is the product of all positive integers less than or equal to n.

Mathematical Formula
n! = n × (n-1) × (n-2) × ... × 1


For example:

5! = 5 × 4 × 3 × 2 × 1 = 120
